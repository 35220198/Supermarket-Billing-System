# Supermarket Billing System

**Description:** Responsive supermarket billing web app in HTML, CSS and JavaScript. Pick a product, set the quantity, add to cart, edit items, see the live total and a receipt, then print or clear. Works on phones, tablets and desktops. No dependencies.

## Files
Keep all three in ONE folder: `index.html`, `style.css`, `script.js`

## Run (PowerShell)
```powershell
cd "C:\Users\-admin\Desktop\supermarket-billing"
python -m http.server 8000
```
Open http://localhost:8000 (Ctrl + F5 after changes).
